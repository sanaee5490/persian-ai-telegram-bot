## 🚀 راه‌اندازی سریع (۳ دقیقه)

### ۱) نصب

```bash
cd telegram-ai-bot
npm install
```

### ۲) گرفتن توکن ربات

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده
2. دستور `/newbot` را بزن
3. یک نام و یک یوزرنیم انتخاب کن
4. توکن دریافتی را کپی کن (چیزی شبیه `123456:ABC-DEF...`)

### ۳) گرفتن کلید رایگان هوش مصنوعی

**گزینهٔ A — Google Gemini (پیشنهادی، کاملاً رایگان):**
برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → `Create API key` → کپی کن

**گزینهٔ B — OpenRouter (مدل‌های رایگان متعدد):**
برو به [openrouter.ai/keys](https://openrouter.ai/keys) → `Create Key` → کپی کن

> می‌توانی هر دو را وارد کنی؛ بات اگر یکی شکست خورد، خودکار به دیگری سوییچ می‌کند.

### ۴) تنظیم فایل `.env`

```bash
cp .env.example .env
```

سپس مقادیر را پر کن:

```env
BOT_TOKEN=123456789:AAEhB...        # توکن از BotFather
GEMINI_API_KEY=AIzaSy...            # کلید Google AI Studio
OPENROUTER_API_KEY=sk-or-...        # اختیاری
ADMIN_IDS=123456789                 # آی‌دی عددی خودت از @userinfobot
```

### ۵) اجرا

```bash
npm run dev
```

تمام! به رباتت در تلگرام `/start` بفرست 🎉

## ⚙️ تنظیمات کامل `.env`

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | **الزامی** — توکن از BotFather |
| `ADMIN_IDS` | — | آی‌دی ادمین‌ها با کاما، مثلاً `123,456` |
| `AI_PROVIDER` | `auto` | `auto` / `gemini` / `openrouter` |
| `GEMINI_API_KEY` | — | کلید Google AI Studio |
| `OPENROUTER_API_KEY` | — | کلید OpenRouter |
| `DEFAULT_MODEL` |  `gemini-3.8-flash` | مدل پیش‌فرض |
| `SYSTEM_PROMPT` | فارسی | شخصیت پایهٔ دستیار |
| `TEMPERATURE` | `0.7` | خلاقیت (۰ تا ۲) |
| `MAX_TOKENS` | `2048` | حداکثر طول پاسخ |
| `MAX_HISTORY` | `12` | تعداد پیام‌های حافظه |
| `RATE_LIMIT_PER_MINUTE` | `15` | محدودیت نرخ هر کاربر |
| `ENABLE_WEB_SEARCH` | `true` | فعال/غیرفعال کردن جستجوی وب |
| `PORT` | `3000` | پورت داشبورد وب |
| `PUBLIC_URL` | `http://localhost:3000` | آدرس عمومی برای مینی‌اپ |
| `DB_PATH` | `./data/bot.db` | مسیر دیتابیس SQLite |

## 📱 فعال‌سازی مینی‌اپ تلگرام

مینی‌اپ یک رابط چت تحت وب است که **داخل خود تلگرام** اجرا می‌شود.

1. ربات را روی یک دامنهٔ HTTPS اجرا کن (مثلاً Railway، Render، یا سرور خودت)
2. `PUBLIC_URL` را به آن آدرس تنظیم کن
3. به [@BotFather](https://t.me/BotFather) برو →
   `/mybots` → انتخاب ربات → `Bot Settings` → `Menu Button` → آدرس `/miniapp` را وارد کن

> امنیت: مینی‌اپ داده‌های `initData` تلگرام را با **HMAC-SHA256** و توکن ربات اعتبارسنجی می‌کند؛ جعل هویت ممکن نیست.

## 🌐 دیپلوی رایگان

### Railway
```bash
npm i -g @railway/cli
railway login && railway init && railway up
```

### Render
- New → Web Service → اتصال به ریپو
- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- متغیرهای `.env` را در پنل تنظیمات وارد کن

### هر سرور لینوکسی
```bash
npm install
npm run build
npm start
# یا با PM2:
pm2 start dist/index.js --name ai-bot
```

> ⚠️ برای مینی‌اپ حتماً HTTPS لازم است. برای داشبورد وب همیشه پورت `0.0.0.0` bind می‌شود.

### 🔊 محدودیت رایگان متن به صدا

سقف رایگان Gemini برای هر مدل TTS **۱۰ درخواست در روز** است. ربات به‌طور خودکار
سه مدل را پشت‌سرهم امتحان می‌کند (`gemini-3.8-flash-tts` →
`gemini-3.8-flash-lite-tts` → `gemini-3.1-flash-tts-preview`) پس سقف مؤثر
**۳۰ درخواست در روز** می‌شود. اگر هر سه پر باشند، پیام واضح دریافت می‌کنید.

## 🔒 نکات امنیتی

- فایل `.env` هرگز در گیت commit نشود (در `.gitignore` است)
- توکن ربات را در کد hard-code نکن
- کلیدهای API را فقط در متغیرهای محیطی نگه دار
- اگر توکن لو رفت، فوراً در BotFather با `/revoke` باطلش کن

## 🐛 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `توکن ربات تنظیم نشده` | فایل `.env` ساخته شود و `BOT_TOKEN` پر باشد |
| `هیچ کلید هوش مصنوعی تنظیم نشده` | `GEMINI_API_KEY` یا `OPENROUTER_API_KEY` لازم است |
| پورت اشغال است | مقدار `PORT` را در `.env` تغییر بده |
| `401 Unauthorized` در تلگرام | توکن را دوباره از BotFather کپی کن |
| پاسخ‌ها کوتاه است | `MAX_TOKENS` را زیادتر کن |
| خطای محدودیت نرخ | `RATE_LIMIT_PER_MINUTE` را افزایش بده |
